# C1 diagnosis, 2026-09-26 (read-only review; nothing under `bus/` was changed)

Scope: why C1 (live Alpaca, $50, `survive` branch) is not learning or earning, and what is fragile. Every line reference
below was re-read against the code on 2026-09-26 ~01:50 PDT. Fixes are proposals (protected files; the owner reviews them
through the change gate), see "Proposals" at the end.
