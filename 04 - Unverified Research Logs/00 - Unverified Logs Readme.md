## Known data-quality issues found during reorganization
- Two notes ("Multi-Agent Design Patterns" and "Multi-Agent Systems")
  turned out to be the same 5-source search result set generated twice
  under different titles ~20 minutes apart. Merged into one file.
- One note ("Prompt Engineering") has a `search_query` field naming DSPy/
  MIPROv2, but its actual retrieved content is generic prompt-engineering
  links with no DSPy content at all -- the daemon's search-to-topic
  matching doesn't appear fully reliable. Kept as-is (the content itself
  is legitimate) but flagged in the file.
- Worth knowing if more autonomous research output is added later: check
  for this class of mismatch before trusting a file's title/search_query
  to accurately describe its content.
